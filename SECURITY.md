# Security

This tool handles authenticated exports, potentially private archives, local media
files and administrative writes inside Mastodon. Run it only on archives you
trust, back up destination data, and test new releases away from production first.

For a sensitive vulnerability, use the repository's **Security → Report a
vulnerability** feature if available. If private reporting is unavailable, open a
minimal issue asking for a private contact channel without posting exploit data,
credentials or private content. Do not upload real export archives to public
issues.

Only the latest published tool release is maintained. Supported destination
versions are listed explicitly in README.MD; the version guard is part of the
compatibility boundary, not a general guarantee about the destination server.
